# PD Soluções Digitais — UI aprovada consolidada

Esta pasta reúne as referências de interface aprovadas do Portal do Cliente e do Painel PD.

## Branch
`portal-ui-consolidado`

## Regra principal
Estas versões foram aprovadas visualmente. O Codex deve usá-las como referência de implementação e **não redesenhar** a interface sem uma nova decisão explícita do projeto.

## Fontes
- `approved-ui/sources/`: HTML/CSS aprovados e otimizados para consulta no GitHub.
- `approved-ui/assets/`: imagens e logos necessários às fontes consolidadas.
- `docs/`: decisões, regras comerciais e mapa do Portal.

## Integração
O próximo passo é o Codex consolidar essas telas em uma aplicação única, conectar rotas, componentes, formulários, Supabase, geração de protocolos, uploads, cálculo de rota e Painel PD.

A `main` não deve ser substituída diretamente durante esta etapa. Trabalhar primeiro em branch de integração/preview.
