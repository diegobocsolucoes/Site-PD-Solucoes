# PD Soluções Digitais — UI Aprovada Consolidada

Esta pasta contém os HTML/CSS das versões visuais aprovadas do Portal do Cliente e do Painel PD/Admin.

## Regras
- Estas versões são referências visuais aprovadas.
- Codex deve preservar layout, identidade, hierarquia e fluxos.
- Assets foram consolidados em `approved-ui/assets/` e otimizados apenas para armazenamento/preview no GitHub.
- A implementação funcional final pode reorganizar componentes, desde que preserve a aparência e o comportamento aprovados.
- Não alterar a branch `main` diretamente durante integração; trabalhar em branch de implementação/preview.
