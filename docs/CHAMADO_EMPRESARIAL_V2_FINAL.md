# Chamado / Atendimento Empresarial — V2 FINAL

Status: versão visual final aprovada.

## Direção visual
- Identidade preto/grafite com verde oficial PD.
- Tipografia em caixa alta.
- Logo oficial preservada.
- Cards retangulares, bordas verdes discretas e linguagem tecnológica.
- Continuidade visual com Home V15, Área para Empresas V3 e demais telas aprovadas.

## Estrutura
- Dados da empresa e responsável.
- WhatsApp obrigatório.
- E-mail.
- CNPJ opcional.
- Protocolo anterior opcional.
- Escolha: Chamado avulso / Usar pacote / Não sei.
- Equipamento: Desktop / Notebook.
- Catálogo de problemas e serviços.
- Descrição detalhada.
- Prioridade / impacto.
- Indicação se o mesmo problema já foi tratado.
- Suporte remoto ou atendimento presencial.
- CEP para cobertura.
- Regra de deslocamento.
- Resumo para revisão.
- Valor aparece somente quando houver contexto suficiente.
- Chamado avulso padrão: R$ 70.
- Pacote pode consumir 1 chamado.
- Regra: 1 problema = 1 chamado.
- Reabertura do mesmo problema em até 7 dias sujeita a avaliação.
- Confirmação universal futura com protocolo PD-EMP-2026-XXXX.
