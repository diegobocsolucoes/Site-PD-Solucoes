# Painel PD / Admin — Solicitações V1 FINAL

Status: versão visual final aprovada.

## Direção visual
- Identidade preto/grafite com verde oficial PD.
- Tipografia em caixa alta.
- Continuidade visual com o Dashboard Admin V2.
- Interface administrativa privada, densa e organizada para operação diária.
- Cards retangulares, status visuais, filtros e painel lateral de detalhe.

## Estrutura
- Visão geral da fila.
- Contadores por status:
  - Novo
  - Aguardando contato
  - Agendado
  - Em atendimento
  - Aguardando cliente
  - Concluído
- Filtros por status, tipo, prioridade e período.
- Busca por protocolo, cliente, empresa ou WhatsApp.
- Tabela de solicitações.
- Protocolo, tipo, cliente/empresa, prioridade, status e última atualização.
- Painel lateral com solicitação selecionada.
- Dados de contato.
- Equipamento.
- Modalidade.
- Descrição do problema.
- Próxima ação recomendada.
- Alteração de status.
- Ações: WhatsApp, Agendar, Abrir solicitação completa.
- Histórico em linha do tempo.
- Paginação.

## Protocolos suportados
- PD-SV
- PD-OR
- PD-EMP
- PD-TI
- PD-SE
- PD-CD
- PD-ST
- PD-LJ
- PD-PAR
