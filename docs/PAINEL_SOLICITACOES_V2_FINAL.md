# Painel PD / Solicitações — V2 FINAL

Status: versão visual final aprovada. Esta documentação substitui a referência anterior V1.

## Estrutura aprovada
- Sidebar e identidade alinhadas ao Dashboard V2.
- Indicadores de fila operacional.
- Busca por protocolo, cliente, empresa ou WhatsApp.
- Filtros por status, tipo, prioridade e período.
- Tabela de solicitações com protocolo, tipo, cliente/empresa, prioridade, status e atualização.
- Painel lateral da solicitação selecionada.
- Dados de contato.
- Equipamento e modalidade.
- Descrição do problema.
- Próxima ação.
- Alteração de status.
- Ações: WhatsApp, Agendar e Abrir solicitação completa.
- Histórico em linha do tempo.
- Paginação.

## Status operacionais
Novo → Aguardando contato → Cliente contatado → Orçamento enviado → Aguardando cliente → Agendado → Em atendimento → Aguardando peça/cliente → Concluído → Cancelado → Não convertido.
