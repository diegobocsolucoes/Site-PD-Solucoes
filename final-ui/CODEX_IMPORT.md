# Instrução de importação para Codex

Objetivo: importar os HTML/ZIP aprovados no diretório `final-ui/` da branch `portal-ui-final` e iniciar a integração sem redesenhar.

1. Ler primeiro `final-ui/README.md`, `final-ui/MANIFESTO.md` e todos os arquivos `docs/*FINAL.md`.
2. Importar os artefatos aprovados com os nomes/versões descritos no manifesto.
3. Preservar os assets oficiais e a logo PD.
4. Não alterar o visual durante a importação.
5. Validar que cada HTML abre isoladamente antes de iniciar refatoração.
6. Depois, criar componentes reutilizáveis e rotas da aplicação mantendo fidelidade visual.
7. Não fazer merge em `main` até existir preview revisado.
